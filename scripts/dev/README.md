# scripts/dev/

One-off development and debugging scripts used during initial model evaluation.
Not required to run the application.

| Script | Purpose |
| :--- | :--- |
| `list_groq_models.py` | Lists available Groq model IDs |
| `inspect_groq_response.py` | Inspects raw Groq API response structure |
| `test_groq_models.py` | Quick smoke-test for Groq model availability |
| `test_groq_reasoning.py` | Tests Groq reasoning-format prompts |
| `test_reasoning_formats.py` | Compares reasoning output formats across models |
| `find_working_model.py` | Scans for a working/available Groq model ID |
